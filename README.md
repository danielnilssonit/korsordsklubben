# Korsordsklubben

Svenska korsord, med ledtrådarna i rutorna och små pilar som i tidningens kryss. Gjort för surfplatta, men fungerar
också på mobil och dator. En del av Träffpunkt Hemma.

**Lös:** https://danielnilssonit.github.io/korsordsklubben/

- **Dagens kryss:** ett Lilla kryss (lättare) och ett Stora kryss varje dag, samma för alla.
- **Stort och tydligt:** ledtråden står stort bredvid krysset och kan läsas upp. Stora knappar i bokstavsordning.
- **Hjälp:** visa en bokstav eller ett ord, rätta, eller låt fel bokstäver synas direkt.
- **Lös tillsammans:** skapa ett rum och dela koden eller länken. Alla skriver i samma kryss från var sin skärm.
- **Korsordsstund på tv:n:** `#tv` visar krysset stort med en kod som alla i salen, eller hemma, går in med.
- **Skriv ut:** dagens kryss på A4, med facit om man vill.

Kryssen och ledtrådarna är gjorda för Korsordsklubben. Orden kommer från vanliga svenska ord, och varje
ledtråd är skriven och granskad för att passa den som har löst kryss i hela sitt liv. Man löser tillsammans via
öppna MQTT-servrar (inget konto, bara ett förnamn). Den här mappen byggs automatiskt (tools/build-pages.mjs i projektet).
